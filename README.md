# tenbri.com

Landing page, docs and blog for [Tenbri](https://github.com/tenbri/tenbri). Astro + [Starlight](https://starlight.astro.build) + [starlight-blog](https://github.com/HiDeoo/starlight-blog).

```sh
pnpm install
pnpm dev     # http://localhost:4321
pnpm build   # static site in dist/
```

| Path | What |
|---|---|
| `src/content/docs/index.mdx` | Landing page |
| `src/content/docs/docs/` | Docs (sidebar is autogenerated; order with `sidebar.order`) |
| `src/content/docs/blog/` | Blog posts (`date`, `authors`, `tags`, `excerpt` frontmatter) |
| `src/styles/theme.css` | Design tokens, sampled from the mascot |

## Excalidraw illustrations in posts

1. Draw on [excalidraw.com](https://excalidraw.com).
2. Animate it with [excalidraw-animate](https://dai-shi.github.io/excalidraw-animate/) and export SVG with a transparent background.
3. Save it next to the post as `_assets/<name>.excalidraw.svg` and use `![alt text](./_assets/<name>.excalidraw.svg)`.

The `.excalidraw` in the name makes dark mode invert the drawing, like excalidraw.com does.

## Deploy

Cloudflare Pages, Git integration: build command `pnpm build`, output directory `dist`. Every PR gets a preview URL.
