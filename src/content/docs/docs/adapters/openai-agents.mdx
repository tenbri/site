`TenbriRecorder` records what an agent of the
[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) does: each tool call as an
intent and an outcome, refused calls, handoffs between agents, and the approvals a person gives.
Both recorders write the same entries, but they hook into the SDK differently: the Python SDK awaits
its run hooks, the JavaScript SDK does not (see [How each SDK is hooked](#how-each-sdk-is-hooked)).

### 2. Add the recorder

<Tabs syncKey="lang">
<TabItem label="Python">

Pass the recorder as `hooks=` and its `run_config()` as `run_config=`:

```python title="agent.py"
import asyncio
from agents import Agent, Runner, function_tool
from tenbri import AsyncTenbri
from tenbri_openai_agents import TenbriRecorder


@function_tool
def lookup_order(order: str) -> str:
    """Looks up the shipping status of an order."""
    return f"order {order} shipped"


async def main():
    log = await AsyncTenbri.open("./audit", create=True)
    agent = Agent(name="support", instructions="Answer order questions.", tools=[lookup_order])
    recorder = TenbriRecorder(log, target=lambda tool, args: f"order:{args['order']}")
    async with recorder:
        result = await Runner.run(
            agent, "Where is order 1042?", hooks=recorder, run_config=recorder.run_config()
        )
    print(result.final_output)
    print("pin this:", log.fingerprint)
    await log.close()


asyncio.run(main())
```

</TabItem>
<TabItem label="TypeScript">

`instrument` the agent, then `flush()` after the run:

```ts title="agent.ts"
import { Agent, run, tool } from '@openai/agents'
import { Tenbri } from 'tenbri'
import { TenbriRecorder } from '@tenbri/openai-agents'
import { z } from 'zod'

const lookupOrder = tool({
  name: 'lookup_order',
  description: 'Looks up the shipping status of an order.',
  parameters: z.object({ order: z.string() }),
  execute: async ({ order }) => `order ${order} shipped`,
})

const log = await Tenbri.open('./audit', { create: true })
const recorder = new TenbriRecorder(log, { target: (_tool, args) => `order:${args.order}` })
const agent = recorder.instrument(
  new Agent({ name: 'support', instructions: 'Answer order questions.', tools: [lookupOrder] }),
)
const result = await run(agent, 'Where is order 1042?')
await recorder.flush()
console.log(result.finalOutput)
console.log('pin this:', log.fingerprint)
await log.close()
```

## Configuration

`TenbriRecorder(log, ...)` in Python (keyword arguments), `new TenbriRecorder(log, { ... })` in
TypeScript.

| Python | TypeScript | Default | What it does |
| --- | --- | --- | --- |
| `tools` | `tools` | every tool (TypeScript: every function tool) | Names to record, or a predicate of the tool name. |
| `action` | `action` | the tool name | Maps a tool name to `action.type`. |
| `target` | `target` | none | `(tool, args)` to `action.target`, from the parsed arguments. |
| `inputs` | `inputs` | none | `(tool, args)` to the inputs the call relied on: each `{ref, version, content}` (digested with the stream's digest key) or `{ref, version, digest}`. |
| `subject` | `subject` | none | The pseudonymous handle of the person the run is about, for per-subject keys and erasure. |
| `fail_open` | `failOpen` | `False` / `false` | Let actions run, unrecorded, when the stream cannot be written. A warning is logged. |
|  | `isError` | the SDK's error and timeout messages | Whether a tool's output means it failed. |

Methods:

| Python | TypeScript | What it does |
| --- | --- | --- |
| `read(ref, version, content)` | `read(ref, { version, content })` | Pins what the agent read to the next decision, by keyed digest. Pass `digest` instead of `content` if you already have one. Needs `digest_key` / `digestKey` at open to digest content. |
| `await approve(state, item, by, always=False)` | `await approve(state, item, by, { alwaysApprove })` | Records an `approval` by `by`, then approves the item on the run state. |
| `await reject(state, item, by, message=None)` | `await reject(state, item, by, { message })` | Records the call as `refused` by `by`, then rejects it. |
| `run_config(base=None)` | | Returns your `RunConfig` with a tool error formatter that tells the recorder which tool calls raised. Your formatter still decides the message. |
| `async with recorder:` | | Closes intents still open when the run raises: `error`, or `unknown` when cancelled. |
| | `instrument(agent)` | Adds the recorder to the agent's function tools and handoffs, and to the agents it hands off to. Returns the agent. |
| | `await flush()` | Waits for the entries written in the background and throws the first that failed. |

Pinning the policy the agent read, so the decision names the version it relied on:

## Approvals

The SDK pauses a run when a tool's `needs_approval` (`needsApproval`) says so, and returns the
pending calls as `result.interruptions`. Call `recorder.approve` or `recorder.reject` for each one
instead of approving on the run state yourself:

- `approve` writes the `approval` entry **first**, then approves the item. When the run resumes,
  the tool's intent carries `approval: {by, entry}`, the entry hash of that approval.
- `reject` writes an intent and a `refused` outcome whose `principal` is the person who rejected it,
  then rejects the item.

Calls the model asked for that never started (a tool input guardrail stopped them) are recorded as
`refused` without a person.

Refunds over 50 EUR need a person; this one approves up to 100 EUR and rejects the rest:

<Tabs syncKey="lang">
<TabItem label="Python">

```python title="refunds.py"
import asyncio
import json
from agents import Agent, Runner, function_tool
from tenbri import AsyncTenbri
from tenbri_openai_agents import TenbriRecorder


async def over_50(ctx, args, call_id):
    return args["amount"] > 50


@function_tool(needs_approval=over_50)
def issue_refund(charge: str, amount: int) -> str:
    """Refunds `amount` EUR on the card charge `charge`."""
    return f"refunded {amount} EUR on {charge}"


def ask_a_person(item):
    # Your review step: a ticket, a Slack button, a CLI prompt. Here: refunds up to 100 EUR pass.
    return json.loads(item.arguments)["amount"] <= 100


async def main():
    log = await AsyncTenbri.open("./audit", create=True)
    agent = Agent(name="support", instructions="You handle refunds.", tools=[issue_refund])
    recorder = TenbriRecorder(log, target=lambda tool, args: f"stripe:{args['charge']}")
    async with recorder:
        run_config = recorder.run_config()
        result = await Runner.run(agent, "Refund ch_1, ch_2 and ch_3.", hooks=recorder, run_config=run_config)
        while result.interruptions:
            state = result.to_state()
            for item in result.interruptions:
                if ask_a_person(item):
                    await recorder.approve(state, item, "person:alice")
                else:
                    await recorder.reject(state, item, "person:alice", message="over the limit")
            result = await Runner.run(agent, state, hooks=recorder, run_config=run_config)

    for m in await log.query(action="issue_refund"):
        e = m.entry
        who = f"{e['principal']['kind']}:{e['principal']['id']}"
        print(e["seq"], e["kind"], e.get("phase", ""), e.get("status", ""), who, e["action"]["target"])
    await log.close()


asyncio.run(main())
```

</TabItem>
<TabItem label="TypeScript">

```ts title="refunds.ts"
import { Agent, Runner, tool, type RunToolApprovalItem } from '@openai/agents'
import { Tenbri } from 'tenbri'
import { TenbriRecorder } from '@tenbri/openai-agents'
import { z } from 'zod'

const issueRefund = tool({
  name: 'issue_refund',
  description: 'Refunds `amount` EUR on the card charge `charge`.',
  parameters: z.object({ charge: z.string(), amount: z.number() }),
  needsApproval: async (_context, { amount }) => amount > 50,
  execute: async ({ charge, amount }) => `refunded ${amount} EUR on ${charge}`,
})

// Your review step: a ticket, a Slack button, a CLI prompt. Here: refunds up to 100 EUR pass.
const askAPerson = (item: RunToolApprovalItem) =>
  item.rawItem.type === 'function_call' && JSON.parse(item.rawItem.arguments).amount <= 100

const log = await Tenbri.open('./audit', { create: true })
const recorder = new TenbriRecorder(log, { target: (_tool, args) => `stripe:${args.charge}` })
const agent = recorder.instrument(new Agent({ name: 'support', instructions: 'You handle refunds.', tools: [issueRefund] }))

const runner = new Runner()
let result = await runner.run(agent, 'Refund ch_1, ch_2 and ch_3.')
while (result.interruptions.length) {
  for (const item of result.interruptions) {
    if (askAPerson(item)) await recorder.approve(result.state, item, 'person:alice')
    else await recorder.reject(result.state, item, 'person:alice', { message: 'over the limit' })
  }
  result = await runner.run(agent, result.state)
}
await recorder.flush()

for (const { entry: e } of await log.query({ action: 'issue_refund' })) {
  console.log(e.seq, e.kind, e.phase ?? '', e.status ?? '', `${e.principal?.kind}:${e.principal?.id}`, e.action?.target)
}
await log.close()
```

## Choose where entries go

The stream is wherever `open` points. The recorder does not change; only the URL does.

| Location | URL | Credentials |
| --- | --- | --- |
| A local directory | `./audit` or `file:///var/lib/audit/support` | none |
| AWS S3, MinIO | `s3://bucket/prefix` | `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`; `AWS_ENDPOINT_URL` (and `AWS_ALLOW_HTTP=true` for plain HTTP) for MinIO |
| Cloudflare R2 | `r2://bucket/prefix` | `CLOUDFLARE_ACCOUNT_ID`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` |

## Test your agent offline

Give the agent a scripted model: a `Model` that returns the next prepared turn. The SDK runs as
usual, with no API key and no network, and you assert on what the stream holds. The adapter's own
tests work this way.

<Tabs syncKey="lang">
<TabItem label="Python">

```python title="test_agent.py"
import asyncio
import json

from agents import Agent, Runner, function_tool, set_trace_processors
from agents.items import ModelResponse
from agents.models.interface import Model
from agents.usage import Usage
from openai.types.responses import ResponseFunctionToolCall, ResponseOutputMessage, ResponseOutputText
from tenbri import AsyncTenbri
from tenbri_openai_agents import TenbriRecorder

set_trace_processors([])  # no API key: export traces nowhere (entries still carry their ids)


class Scripted(Model):
    """Plays the model's turns from a script: no API key, no network."""

    def __init__(self, *turns):
        self.turns = list(turns)

    async def get_response(self, *args, **kwargs):
        return ModelResponse(output=self.turns.pop(0), usage=Usage(), response_id=None)

    def stream_response(self, *args, **kwargs):
        raise NotImplementedError


def call(name, call_id, **args):
    return ResponseFunctionToolCall(
        id=call_id, call_id=call_id, type="function_call", name=name, arguments=json.dumps(args)
    )


def say(text):
    content = [ResponseOutputText(text=text, type="output_text", annotations=[])]
    return ResponseOutputMessage(id="m", type="message", role="assistant", status="completed", content=content)


@function_tool
def lookup_order(order: str) -> str:
    """Looks up the shipping status of an order."""
    return f"order {order} shipped"


def test_tool_call_is_recorded(tmp_path):
    async def main():
        log = await AsyncTenbri.open(tmp_path / "audit", keys=tmp_path / "keys", create=True)
        model = Scripted([call("lookup_order", "c1", order="1042")], [say("Shipped.")])
        agent = Agent(name="support", tools=[lookup_order], model=model)
        recorder = TenbriRecorder(log, target=lambda tool, args: f"order:{args['order']}")
        async with recorder:
            await Runner.run(agent, "Where is 1042?", hooks=recorder, run_config=recorder.run_config())

        entries = [m.entry for m in await log.query(action="lookup_order")]
        assert [(e["phase"], e.get("status")) for e in entries] == [("intent", None), ("outcome", "ok")]
        assert entries[0]["action"]["target"] == "order:1042"
        assert entries[0]["principal"] == {"kind": "agent", "id": "support"}
        assert (await log.verify(log.fingerprint)).ok
        await log.close()

    asyncio.run(main())
```

```ts title="agent.test.ts"
import { test } from 'node:test'
import assert from 'node:assert/strict'
import { mkdtempSync } from 'node:fs'
import { tmpdir } from 'node:os'
import { join } from 'node:path'
import { Agent, Runner, Usage, setTraceProcessors, tool, type AgentOutputItem, type Model } from '@openai/agents'
import { Tenbri } from 'tenbri'
import { TenbriRecorder } from '@tenbri/openai-agents'
import { z } from 'zod'

setTraceProcessors([]) // no API key: export traces nowhere (entries still carry their ids)

/** Plays the model's turns from a script: no API key, no network. */
function scripted(...turns: AgentOutputItem[][]): Model {
  return {
    async getResponse() {
      return { output: turns.shift() ?? [], usage: new Usage(), responseId: undefined }
    },
    getStreamedResponse() {
      throw new Error('not scripted')
    },
  }
}
const call = (name: string, callId: string, args: object): AgentOutputItem => ({
  type: 'function_call', name, callId, arguments: JSON.stringify(args), status: 'completed',
})
const say = (text: string): AgentOutputItem => ({
  type: 'message', role: 'assistant', status: 'completed', content: [{ type: 'output_text', text }],
})

const lookupOrder = tool({
  name: 'lookup_order',
  description: 'Looks up the shipping status of an order.',
  parameters: z.object({ order: z.string() }),
  execute: async ({ order }) => `order ${order} shipped`,
})

test('a tool call is recorded', async () => {
  const dir = mkdtempSync(join(tmpdir(), 'audit-'))
  const log = await Tenbri.open(join(dir, 'audit'), { keys: join(dir, 'keys'), create: true })
  const model = scripted([call('lookup_order', 'c1', { order: '1042' })], [say('Shipped.')])
  const recorder = new TenbriRecorder(log, { target: (_tool, args) => `order:${args.order}` })
  const agent = recorder.instrument(new Agent({ name: 'support', tools: [lookupOrder], model }))
  await new Runner().run(agent, 'Where is 1042?')
  await recorder.flush()

  const entries = (await log.query({ action: 'lookup_order' })).map((m) => m.entry)

  assert.equal(entries[0].action?.target, 'order:1042')
  assert.ok((await log.verify(log.fingerprint!)).ok)
  await log.close()
})
```

## Troubleshooting

| Message | Cause | What to do |
| --- | --- | --- |
| Python: `UserError: Error running tool lookup_order: closed`, caused by `StoreUnavailableError('closed')` | The intent could not be written (here the stream was closed), so the run stopped before the tool ran. | Keep the stream open for the whole run. Any write failure surfaces this way: check the `__cause__`. |
| TypeScript: `ToolCallError: Failed to run function tools: StoreUnavailableError: closed` | The same, from the `tenbri` guardrail; `error.error` is the `TenbriError`. | The same. |
| `tenbri: not recorded, the action goes ahead (fail_open): closed` (`failOpen` in TypeScript) | `fail_open` is on and the stream could not be written; the tool ran. | Fix the stream; the call is not in the record. |
| `InvalidRequestError: a digest needs digest_key at open, or pass digest= to read() yourself` | `read()` or an `inputs` mapping gave `content`, but the stream has no digest key. | Open with `digest_key` (`digestKey`), or pass a `digest` you computed. |
| `Error: already recorded by another TenbriRecorder` (TypeScript) | `instrument` was called on an agent or tool another recorder already instruments. | Use one recorder per agent, or build fresh tools for a second recorder. |
| Tools that raised are recorded `ok` (Python) | `run_config=recorder.run_config()` is missing, and the tool has its own error function. | Pass `run_config`. On `openai-agents` 0.23 only the SDK's default error message tells; upgrade to 0.24. |
| An MCP tool has no entries (TypeScript) | Tools an agent gets at run time are not instrumented, and only function tools are recorded. | Wrap the call by hand ([any framework](/docs/adapters/planned/#use-tenbri-from-any-framework-today)). |
| `broken at seq 1: untrusted_root: the genesis key is sha256:e3ed75b1…, not the pinned sha256:0edc8058…` | You verified against another stream's fingerprint (here a stream that was deleted and created again). | Pin the fingerprint printed when this stream was created. |
| `tenbri.errors.NotFoundError: no stream at ./audit: ./audit is not a directory` | `open` without `create` on a path with no stream. | Pass `create=True` (`create: true`) the first time, or fix the path. |

A process that dies mid-tool leaves its intent open; the next writer of the stream records it as
`unknown`.

## How each SDK is hooked

- **Python** passes the recorder as `hooks=` (it is a `RunHooks`). The SDK awaits `on_tool_start`,
  so the intent is durable before the tool runs, and a failed write stops the run. Use one recorder
  per run, or per conversation when a run resumes after approvals: it keeps the calls in flight.
- **TypeScript** cannot rely on run hooks: the JavaScript SDK emits them as events and does not
  wait. `instrument` adds a tool input guardrail named `tenbri` to each recorded tool, after the
  tool's own guardrails. The SDK awaits it before the tool runs, so a failed write stops the tool.
  Outcomes and handoffs are written in the background, in order; the next intent and `flush()` wait
  for them. A recorder can serve many runs.

## What is written

| What happens | Entry |
| --- | --- |
| A tool call | An `intent` by `agent:<name>`, action the tool name, durable before the tool runs; then the outcome `ok`, or `error` if the tool raised or timed out |
| A tool input guardrail rejects or trips, or a person rejects the call | An intent and the outcome `refused` (with the person as `principal`, for a rejection) |
| A handoff | An intent and an `ok` outcome, action `handoff`, target `agent:<next agent>` |
| `approve(...)` | An `approval` entry; the tool's intent names it in `approval` |
| The run raises (Python, inside `async with`) | Open intents end in `error`, or `unknown` when the run was cancelled |

Tool arguments, results and prompts are never written. Entries carry the SDK's trace id (span ids
cut to 16 hex digits; the first 16 still find the span), so a decision and its trace find each
other. Python non-function tools (computer, shell) carry no call id in their hooks, so the recorder
tracks one call at a time per such tool.
