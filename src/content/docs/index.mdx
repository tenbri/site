## Logs say what happened. Tenbri proves it.

<CardGrid stagger>
	<Card title="Tamper-evident" icon="seti:lock">
		Every entry is hash-chained and signed. Change one byte and verification fails.
	</Card>
	<Card title="Who, why, from what" icon="magnifier">
		The agent that acted, the rule and policy version that allowed it, and the inputs it saw,
		pinned by content hash.
	</Card>
	<Card title="Humans in the loop" icon="approve-check">
		Approvals and overrides are their own signed entries, not a Slack thread.
	</Card>
	<Card title="Your storage" icon="seti:folder">
		Plain files on local disk, S3, Cloudflare R2 or MinIO. No hosted service, no telemetry.
	</Card>
	<Card title="Receipts auditors verify offline" icon="document">
		Share proof without sharing access to your systems.
	</Card>
	<Card title="Any agent stack" icon="puzzle">
		Rust today; Python, Node and a WASM verifier next. A `tenbri` CLI and the `tenbrid` REST and gRPC API.
	</Card>
</CardGrid>
